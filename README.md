# AAHARA

A premium tiffin service for international residents in Busan, Korea.

## Features

- Customer homepage with weekly food menu
- Tiffin customizer with live pricing
- Food profile and recommendations
- Order once + subscriptions and My Aahara dashboard
- Feedback and food requests
- Admin dashboard with menu, orders, customers, subscriptions, demand planner
- Local mock storage for a future backend integration

## Run locally

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```

## Notes

- Customer browsing is public
- Checkout and account flows require login in the prototype
- Admin login is available in the demo auth screen
